# 成稿前与成稿后的双轮体检

## 第一轮：动笔前的证据与逻辑检查

为每问做一行证据台账：`题目要求 → 输入及版本 → 假设 → 变量/目标/约束 → 求解日志 → 输出文件与行列 → 独立检查 → 可写结论`。任何箭头断开，都先补证据或收窄表述。给关键主张标记来源状态：**题目给定**、**作者报告**、**本轮复算**、**由材料推导**、**未核实**；不能把作者报告写成本轮独立证实。记录最终方案 ID、随机种子、参数、单位、时间起点和文件哈希；发现旧表与新表混用时，以实际执行输出重算并留下选择理由。

重点排查：

1. **逻辑**：各问输入继承是否一致；实体与共享资源是否被越权重新分配；假设是否被模型违反；结论是否超出模型、求解器或离散检查支持的范围。
2. **数学**：集合、索引、变量、参数和上下标是否先定义；同一符号是否一义；约束方向、极端值、量纲及时间口径是否正确。精确算法与启发式的保证分别陈述。
3. **数值**：从明细表独立复算关键汇总数；核对单位转换、总量、资源峰值、硬时限、重复/遗漏任务、SOC 或库存边界；有差异则优先查源数据与计算过程。
4. **可视化**：先明确图要回答的问题。时序与资源冲突选甘特图/占用图，权衡选 Pareto 散点或曲线，空间覆盖选地图，参数变化选带单位的敏感性曲线。图中不暗示未证明的因果或精度。
5. **引用**：优先审查创新性、基线比较、赛题外部事实和方法来源等高风险主张。将复合句拆为可核对的单一论断；先核实书目信息，再看原文是否直接支持该论断、只支持较窄版本、仅提供背景，或不支持/无法检查。后两种不能当作已验证依据。

若已有论文，先做逆向提纲：逐段写出其回答的问题、主张、证据和下一段的逻辑关系。按**会改变可行性或核心结论 → 数值/引用/符号冲突 → 结构表达 → 版式**处理问题；修改语言时保留原有条件、量词、因果方向及数学确定性。确认输入和输出格式后，尽早导出一页含中文、公式、三线表和图片的样张，先验证工具链，再投入长篇排版。

这一轮的结果应是可以写作的统一口径，而不是单独交付给用户的碎片报告。严重冲突未关闭时，不把草稿称为可投稿终稿。

## 第二轮：成稿后的逐页和逐字段检查

| 检查域 | 必须执行的检查 | 通过条件 |
| --- | --- | --- |
| 结构 | 对照当年官方模板核对章节、摘要/关键词、匿名、附录、页数与字体规则。 | 所有必需部分存在，格式和提交要求无已知冲突。 |
| 逻辑 | 逐句核对摘要、结果表、结论、图注的方案版本和数字；检查假设与模型、前问与后问。 | 每个核心结论都能回到对应证据，限制措辞与验证范围一致。 |
| 公式与符号 | 检索所有公式编号、交叉引用、未定义变量、重复符号、量纲、集合求和下标及约束方向。 | 编号连续或符合模板，首次定义明确，公式可按文字独立理解。 |
| 图表 | 检查标题、图注、轴名、单位、图例、来源、分辨率、可读字体及正文引用；放大检视矢量图和打印尺寸。 | 无无标题或正文未引用的关键图表，无裁切、重叠或低清晰度。 |
| 文献 | 逐条核对来源与书目信息，双向比对正文引用和参考文献列表。 | 无孤立文献、悬空引用或未核实却当作事实的来源。 |
| 语言 | 删除口语、模板提示、空泛赞语和过度确定词；统一术语、时态、有效数字。 | 方法与结果用可核查动词，创新性和推广范围有依据。 |
| 实际文件 | 打开最终 PDF/DOCX/LaTeX 编译结果，逐页检查断页、公式、图片、表格和目录。 | 交付文件能打开，页面完整，关键元素未丢失。 |

若某项不通过，修复后只复查受影响的章节和全篇一致性。不能用“似乎正确”替代明细复算或来源核验。

数值比较还要核对分母、相对百分比与百分点、加权与非加权均值、舍入精度。一次随机运行不支持“稳定”；有限扰动下变化小不支持无条件“鲁棒”；求解器限时退出也不等于已证明最优。引用只证实书目身份时，仍须单独检查其正文是否支持相应论断。

## 质量优化的判据

- **语言专业性**：将“效果很好”改成具体指标、比较对象和适用条件；避免把未验证的稳定性写成事实。
- **论证链**：每个模型选择要能回应题目难点；每个结论要有结果表和检验；每个局限要能引出具体改进。
- **创新性**：先列传统或基线方法在本题的具体不足，再陈述新增的结构、约束处理、耦合机制或验证方式及其代价。若没有基线或消融，只称“设计特点”，不声称性能提升。
- **可视化**：优先少量高信息量图。配色需在灰度打印和色觉差异下可分辨；多方案同尺度比较，标明误差、样本数或无不确定度的原因。
