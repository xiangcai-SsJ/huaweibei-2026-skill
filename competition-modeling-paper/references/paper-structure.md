# 章节写作指南

先核对目标赛事当年的官方模板、页数、摘要页、匿名与附件规则。下表篇幅仅以约 25–35 页中文正文为规划参照，不是任何赛事的官方上限；较短赛制按比例压缩，英文论文按信息密度而非机械字数换算。图表与附录占用仍计入官方规定的页数时，按官方口径处理。

| 章节 | 必须写清的内容 | 建议篇幅 | 常见踩坑与修正 |
| --- | --- | --- | --- |
| 摘要 | 最后撰写；用独立成文的段落交代任务、逐问方法、经核验的关键数值、验证与局限。 | 0.5–1 页 | 只写背景或方法口号、保留模板提示词、把不同版本的数字混用；与正文最终表逐项核对。 |
| 关键词 | 选 3–6 个能检索到对象、模型与方法的术语，顺序与论文主线一致。 | 1–2 行 | 用“算法”“优化”等过泛词，或留下“关键词1”。 |
| 问题重述 | 用自己的话保留任务、输入、输出、硬约束、评价指标和各问递进关系。 | 0.5–1.5 页 | 改写时漏掉禁共享、时限、不可拆分等关键题意；与原题逐条对照。 |
| 问题分析 | 说明难点、分解思路、各问的依赖以及为何选用相应模型。可用一张流程图。 | 1–2 页 | 先吹算法而未解释问题结构；不要把尚未求解的结论写成事实。 |
| 模型假设 | 每条写“内容—必要性—适用条件—可能影响”，区分题设事实和人为简化。 | 0.5–1.5 页 | 假设与约束、数据或后文检验矛盾；不合理的假设须改模型或限定结论。 |
| 符号说明 | 三线表统一列符号、含义、单位、索引或集合；复用符号必须一致。 | 0.5–1.5 页 | 同一字母跨章改义、下标未定义、单位缺失；公式首次出现仍需局部解释。 |
| 模型建立 | 按集合/变量、目标、硬约束、约束解释、模型适用范围递进；对多问说明继承关系。 | 5–9 页 | 只堆公式、遗漏目标或约束方向、把结果指标误写为约束；核对量纲和极端情形。 |
| 模型求解 | 交代算法流程、编码或分解、参数、终止条件、实现环境、可行性修复及复杂度或求解规模。 | 3–6 页 | 不给实际运行设置，或把固定子问题的最优性扩展为全局；记录随机种子和日志。 |
| 结果分析 | 每问给方案表、核心指标、方案解释、对比基线与题目要求的实际输出。 | 3–5 页 | 图表堆叠但不解释、指标定义变化、单位混乱；标题、图注、轴与正文交叉引用齐全。 |
| 模型检验 | 用独立重算、守恒/覆盖/时序检查、约束残差或外部对照验证关键结论。 | 1–2.5 页 | 只展示求解器“成功”而不查原始结果；写明检查范围、精度、失败项。 |
| 灵敏度分析 | 选择有业务意义的参数，报告变化区间、重求或局部扰动方法、趋势和阈值。 | 1–2.5 页 | 把参数扫描当稳定性证明，或无重复实验却声称鲁棒；区分重求与固定解复算。 |
| 模型优缺点 | 优点对应可验证结构或结果；缺点对应简化、求解规模、数据和离散化边界。 | 0.5–1 页 | 空泛称“精度高、通用性强”；每个判断给证据或适用条件。 |
| 改进与推广 | 针对已识别局限提出具体改法、所需新增数据、计算代价与可能适用场景。 | 0.5–1 页 | 无证据宣称可直接部署或适用所有地区；明确哪些部分尚需重新标定。 |
| 结论 | 按题目顺序回答各问，给最终方案、关键量化结果、检验结论和主要限制。 | 0.5–1 页 | 引入正文没有的新结果，或把摘要、结果表和结论写成三个版本。 |
| 参考文献 | 使用赛事要求的体例；正文引用与文献列表双向对应，核实作者、题名、年份、页码、DOI/链接。 | 通常 1–2 页 | 以相似主题文献替代事实来源、引文顺序错乱、虚构卷页。 |
| 附录 | 放可复核但不影响正文连续阅读的推导、参数表、算法伪代码、额外结果和必要代码入口。 | 按官方上限 | 把核心模型或关键结果只藏在附录；检查匿名、文件格式及页数口径。 |

## 不同赛事的适配

- **国赛 CUMCM**：以当年官方模板和题目要求为准；通常优先保证模型建立、求解步骤与结果可复核，摘要简洁覆盖每问。不要把“偏重某项”当成未经核实的评分条款。
- **美赛 MCM/ICM**：以当年官方英文写作、摘要/summary sheet、页数与其他附加材料要求为准；全文英文表达需自然，问题重述、假设及面向决策者的解释要完整。若题目要求备忘录或信件，按官方位置纳入最终论文。
- **华为杯**：核对当年论文模板、赛题附件和提交要求；多问题递进时重点写清前问结果如何成为后问输入、约束和可行性证据。
- **省级赛事或其他赛制**：不套用上述默认模板。以该赛事本届官方文档确定顺序、篇幅、格式和评分重点，再按信息量分配页数。

所有赛事均应先完成数值和逻辑一致性，再处理语言与排版；图表服务于论证，不代替解释。
